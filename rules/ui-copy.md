# UI 文案

UI 文案默认少写。交付界面前把每处辅助小字过一遍：同屏已有的、用户自己定的口径、版面已经表达的、只在正常时说「正常」的、这一层用不上的、同一状态的第二种表示，删掉或挪到下一层。保留要据此行动的数字、异常、不可逆操作前的身份、从界面推不出的换算。

有界面的项目用 `node ~/Documents/workspace/claude-config/ui-copy-check/check.mjs` 断言：项目根的 `ui-copy.json` 列出要查的屏（url 或 setup 脚本，可选每屏的禁词 / 必现词），检查首屏小字条数不超过基线、同屏数字不重复。第一次加 `--update` 建基线，并接进项目的验证脚本。小字只减不增：要加就主动改基线，在汇报里写明加了什么、为什么。
